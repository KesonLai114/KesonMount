# 网盘管家（NetMount）

一个 macOS 原生小应用，把「极空间」等网络硬盘集中管理：图形界面看容量、一键挂载 / 卸载、随时添加新的网络硬盘。

![主界面](docs/预览-主界面.png)

## 为什么做它

之前在系统里挂载极空间（`极空间HD` / `极空间SD`）是手工连 SMB，没有任何界面可以查看状态、容量，也没有统一入口去管理更多网络盘。这个应用把这件事变成一个正经的 App：

- 打开就看到每块盘的**挂载状态、已用 / 剩余容量、挂载路径**
- 一块盘一个卡片，**挂载 / 卸载 / 打开** 一键完成
- 想加群晖、威联通、Windows 共享、坚果云、Nextcloud、Alist、NFS……**加一条配置就行**，不用改代码
- 密码存 macOS 钥匙串，配置里不出现明文

## 功能

| 能力 | 说明 |
| --- | --- |
| 自动纳管 | 首次启动会把系统里已挂载的网络磁盘自动收进来，不用手动录一遍 |
| 挂载 / 卸载 | 双击卡片或点按钮；失败会给出人话提示（密码错、连不上、共享不存在…） |
| 批量挂载 / 卸载 | 底栏一键挂上或卸下全部磁盘，菜单栏和全局快捷键里也有 |
| 容量监控 | 每 4 秒刷新一次，容量条超过 75% / 90% 变色提醒 |
| 添加网盘 | 支持 SMB / WebDAV / NFS，可填端口，统一挂到 `/Volumes/共享名`（和访达一致） |
| WebDAV HTTP | 默认走 HTTPS；局域网里只提供明文 HTTP 的服务（如 Alist 5005 / 5244）可关掉 HTTPS 开关，端口提示同步切到 80 |
| 开机自动挂载 | 每块盘可单独开启，启动 App 时自动连上 |
| 只读挂载 | 以只读方式挂载；挂载后核对实际只读标志，没生效就自动卸载并提示，不会静默变成可写 |
| 密码安全 | 走系统 Security 框架在**进程内**读写钥匙串（不经过命令行，密码不进进程表）；删除磁盘时真删，编辑窗口也能单独清除；导入配置时主机 / 账号变了会作废旧密码 |
| 扫描已挂载 | 手动把新出现的网络磁盘纳管进来（⌘⇧I） |
| 局域网发现 | Bonjour 自动找同网段的 NAS，展开即选共享，一键添加并挂载 |
| 免密挂载 | 密码依次取自：网盘管家存的 → 系统（访达）存的 → 才问你；大多情况直接挂上 |
| 挂载来源可见 | 卡片和编辑框都会说明这块盘是「网盘管家挂载」还是「系统 / 访达挂载」，以及系统实际用的服务器地址 |
| 菜单栏图标 | 顶部菜单栏常驻图标；**左键弹状态面板、右键出完整菜单**（19 项全部带图标）：一键挂载或卸载全部、逐块操作、扫描、添加 |
| 菜单栏状态面板 | 不用切窗口就能看版本号、已挂载汇总、逐块状态与容量，行内直接挂载 / 卸载；每 2 秒自刷 |
| 全局快捷键 | ⌥⌘M 显示 / 隐藏窗口、⌥⌘K 挂载全部、⌥⌘U 卸载全部，在任何 App 里都生效（需辅助功能权限，可整体关闭） |
| 网络唤醒 | 填了网卡 MAC 的盘，端口探不通时先发 Wake-on-LAN 魔术包把睡眠中的 NAS 叫醒，再继续挂载 |
| 按 Wi-Fi 挂载 | 每块盘可设 Wi-Fi 白名单，出门在外不瞎连；回到家（换网）后自动补挂，被跳过时卡片明确标注 |
| 配置备份 | 一键导出 / 导入全部磁盘配置（按盘 ID 合并），密码不进文件，换机不用重填 |
| 运行诊断 | 设置面板一键导出最近的运行日志与配置摘要（自动脱敏），同时写进系统统一日志，可用「控制台」查历史 |
| 开机启动 | 用 macOS 官方登录项（SMAppService）实现，设置面板和菜单栏图标里都能切 |
| 可隐藏程序坞 | 关掉程序坞图标后程序在后台待命，菜单栏图标成为唯一入口，关窗口不退出 |
| 掉线自动重挂 | 后台每 30 秒用「真读一次目录」判断死活，掉了或假死都自动接回来；带指数退避，Mac 休眠唤醒后也会重连 |
| SMB 协议版本可选 | 自动 / 2.1 / 3.0 / 3.1.1 四档可钉死，解决「新 Mac 想谈 3.1.1、老 NAS 只认 2.1」导致的连不上 |
| 连接诊断 | 一键把四个 SMB 版本挨个试一遍，找出能连上的那个并自动存进这块盘的设置 |
| 系统通知 | 掉线与重连成功时发通知；隐藏程序坞图标时这是唯一能主动提醒到你的渠道 |
| 版本号可见 | 主界面标题旁、菜单栏面板、偏好设置「关于」三处都直接显示版本号与构建号 |
| 内置说明书 | 25 页 PDF 随应用打包，菜单「帮助 → 使用说明书」或 ⌘? 直接打开，不用联网 |

改完内容后重新生成 PDF：

```bash
# 首次先编译排版工具
swiftc -O -framework AppKit -framework WebKit -framework PDFKit \
  tools/makepdf.swift -o /tmp/makepdf

# 先输出到本机磁盘，再拷回去
/tmp/makepdf docs/说明书.html /tmp/manual-1.5.0.pdf
cp /tmp/manual-1.5.0.pdf "docs/网盘管家使用说明书-1.5.0.pdf"
```

> 排版源文件是 `docs/说明书.html`，每页固定 794×1122 px（A4 @96dpi）。
> `makepdf` 先用 WKWebView 渲染成一张长页，再按 A4 逐页裁切——比 `NSPrintOperation` 在无窗口环境里可靠。
> 注意：PDF 渲染引擎对**多层 background 渐变**和 `radial-gradient` 支持有 bug，会渲染成色块，排版时只用单层 `linear-gradient`。
> 注意 2：直接往 SMB 卷上的旧 PDF 写会失败（`CGContext` 报「无法创建输出 PDF」/ `EBUSY`），**必须先落到 `/tmp` 再拷**；
> 如果旧 PDF 正被预览器打开，SMB 会锁住它（连改名都不行），这时把新文件存成 `网盘管家使用说明书-<版本>.pdf` 即可——
> `build.sh` / `package.sh` 会按修改时间自动挑 `docs/` 下最新的那一份打进 App。
> 新增页要注意别超出 1122px 高（超了会被裁掉）：`.shot` 里的图用 `style="width:420px"` 之类限宽，别用 100% 宽。
>
> **排版自检（每次改完必看）**：`makepdf` 会量出每页正文的最下沿，直接告诉你哪页压到了页脚——
> ```
> 每页余量：p1 余1066  p2 余217  p4 ✗+174 …
> 排版检查：⚠️ 有 1 页正文压到页脚，会被裁掉：
>    第 4 页超出 174px（正文底 1240，安全线 1066）
> ```
> 出现 ✗ 就把该页的截图调矮、或删几句，直到打印 `N 页全部在安全线内 ✅`。
> 想看某页是哪个元素把正文顶出去的，加 `MAKEPDF_DUMP=1`，会逐页列出每个块的高度、底边和计算字号。
>
> **为什么不能靠 pageZoom 缩小**：`WKWebView.pageZoom < 1` 会触发 WebKit 的最小字号限制（9px），
> 把 12.8px 的正文硬抬到 `9/zoom ≈ 18px`，而 21px 的标题不受影响——字号层级全毁、页面被顶爆。
> 所以 `makepdf` 全程 zoom=1，内容超过 `createPDF` 单页上限（14400pt，1pt=1CSS px）时，
> 改成**分批**渲染（每批 ≤12 页，其余 `display:none`），逐批 createPDF 后统一裁成 A4 追加进同一个文件。
> 每批出图前还会等所有图片 `decode()` 完成，否则偶发整块截图在 PDF 里变成白框。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `⌘N` | 添加网盘 |
| `⌘⇧I` | 扫描已挂载 |
| `⌘R` | 刷新状态 |
| `⌘?` | 打开使用说明书 |
| `⌘,` | 打开偏好设置 |
| `⌘↵` | 表单里保存 |
| `esc` | 关闭弹窗 / 取消编辑 |
| `⌥⌘M` | **全局**：显示 / 隐藏主窗口（在别的 App 里也生效） |
| `⌥⌘K` | **全局**：挂载全部磁盘 |
| `⌥⌘U` | **全局**：卸载全部磁盘 |

> 三个全局快捷键需要「辅助功能」权限（系统设置 › 隐私与安全性 › 辅助功能）。没授权时 App 在前台仍可用，只是别的 App 里按了没反应；偏好设置里有总开关，关掉后组合键交还系统。

界面上的其他动作：双击卡片 = 挂载 / 卸载；卡片右下「⋯」= 编辑连接信息、复制地址、开关「开机挂载」、开关「掉线自动重挂」、连接诊断、立即重新连接、移除。

想立刻检查所有盘是不是真的通：菜单「文件 → 检查所有连接」（菜单栏图标的菜单里也有），会逐块真读一次目录，掉了的当场接回来。

移动窗口：按住左上角应用名附近的空白区拖动即可（右侧的「扫描已挂载 / 刷新 / 添加网盘」按钮不受影响）。App 用透明标题栏铺满了整个窗口，所以拖动区是特意留出来的——它走系统的 `performDrag`，不触发 WebView 重排，手感跟系统标题栏一致。

## 构建与安装

```bash
cd NetMount
./build.sh            # 编译 + 安装到 /Applications + 打开
./build.sh --no-open  # 只编译安装
```

要求：macOS 14+，本机有命令行工具（`xcode-select --install`）。不需要完整 Xcode。

> 注意：`.app` 必须构建在本机磁盘上（脚本已处理）。源码放在网络盘没问题，但 SMB 卷上无法删除目录，构建产物不要放回去。

## 打安装包（拷到别的 Mac 上装）

```bash
./package.sh
```

会在 `dist/` 生成两个文件，都是 **通用二进制（Apple 芯片 + Intel 都能跑）**：

| 文件 | 用途 |
| --- | --- |
| `网盘管家-1.5.0.dmg` | 打开后把图标拖到「应用程序」，最直观 |
| `网盘管家-1.5.0.pkg` | 双击安装，自动装到「应用程序」，适合批量分发 |

安装包内已包含 `安装说明.txt`（含首次打开被系统拦截时的三种放行方法）。

> 应用没有购买苹果开发者证书，只做了本地 ad-hoc 签名，所以在新电脑上第一次打开会被 Gatekeeper 拦一下：
> Control + 点击图标 → 打开；或 `xattr -dr com.apple.quarantine /Applications/网盘管家.app`。
> 想彻底免提示需要 Apple Developer 账号（99 美元/年）做签名与公证。

> 注意：`installer` 不能直接从网络宗卷安装 PKG，先把 pkg 拷到本机磁盘再装。

## 数据与配置

- 磁盘配置：`~/Library/Application Support/NetMount/drives.json`，原子写入；运行期间若被外部改动，写回前会自动备份成 `drives.json.external-<时间戳>`
- 密码：macOS 钥匙串里一条 `NetMount` 记录，按磁盘 ID 索引；不写进配置文件，也不进命令行参数
- 挂载点：固定 `/Volumes/<共享名>`，和访达一致；界面上只读展示，不支持自定义目录

## 挂载是怎么做的

安全底线是 **密码永远不进命令行参数**。`mount_smbfs` / `mount_webdav` 这类用户态挂载器只能把账号密码拼进 URL（同机 `ps` 就能看到），1.4.5 起已彻底移除，现在只走系统挂载器。

SMB / WebDAV 依次尝试：

1. **系统挂载器（首选）**：把 `mount volume "smb://host/share" as user name "…" with password "…"` 这段 AppleScript 通过 **stdin** 喂给 `osascript -`（脚本不进 argv），由 NetFS 挂载到 `/Volumes/<共享名>`。凭据走 AppleScript 的认证参数，不塞进 URL；挂完扫一次 `/sbin/mount` 确认真实落点，位置不对就报错，不会静默换路径。
2. **兜底**：`open smb://…` 交给系统连接（仅 SMB；WebDAV 走 `open https://` 只会开浏览器，所以不启用）。

NFS 先试系统挂载器，失败时给出一条 `sudo mount -t nfs …` 命令让用户自己在终端执行；命令里的主机、路径和挂载点都做了 shell 引号转义，配置内容无法注入。

其它细节：

- SMB 协议版本拼在 URL 查询串上（`?vers=3.1.1`），共享名含中文等非 ASCII 字符会先百分号编码；只读用 `?rdonly`，并在挂载后用 `statfs` 核对只读标志，没生效就自动卸载并提示。
- 挂载前先做主机解析；地址写错立刻报「找不到服务器」，不白等。`.local` 域名在 DNS 超时时放行交给 Bonjour，其它主机名超时仍判失败。
- 所有子进程都有超时：超时先 `terminate`，再 `SIGKILL` + `waitUntilExit()` 回收，并关掉管道与读线程，不留僵尸进程。
- 挂载、卸载、启动自挂与挂载表对账统一排在同一条串行队列上，不会两个操作同时改动同一块盘。

## 常见问题

**点挂载提示「这个共享已经在系统里挂载过了」**
同一共享不能挂两次。先去 Finder 侧边栏断开，或直接用已挂载的那块。

**提示「连不上服务器」**
确认 NAS 开机、SMB 服务开启、Mac 和 NAS 在同一网络；主机名建议用 IP（如 `192.168.31.4`）或 `xxx.local`。

**NFS 挂载失败**
NFS 需要管理员权限，按提示在终端执行 `sudo mount -t nfs …` 即可。

**能不能一次挂整台 NAS（服务器根）？**
不能。macOS 的 NetFS 必须知道共享名才挂得出卷，`smb://host/` 这种地址从来挂不出可用的卷，1.4.4 起已移除「挂载整台服务器」。表单里共享名必填；启动时也会自动清掉老配置里这类残留盘，并一并删除它对应的钥匙串密码。想同时用多个共享，给每个共享各加一块盘即可。

**想换图标 / 界面**
改 `Resources/` 下的文件后重新 `./build.sh`。

## 调试（不影响正常使用）

改界面时不想被窗口打扰，可以让应用「隐身」运行——只截图，不弹窗、不抢焦点、不占 Dock：

```bash
# 隐身截图：窗口不显示在任何桌面（包括你新加的桌面）
NETMOUNT_SNAPSHOT=/tmp/shot.png \
  /Applications/网盘管家.app/Contents/MacOS/NetMount

# 顺便执行一段界面脚本再截图（例如打开编辑弹窗）
NETMOUNT_SNAPSHOT=/tmp/shot.png \
NETMOUNT_SNAPSHOT_JS='openEditor(state.drives[0])' \
  /Applications/网盘管家.app/Contents/MacOS/NetMount
```

- 只要设置了 `NETMOUNT_SNAPSHOT`，就自动进入隐身模式；也可用 `NETMOUNT_HEADLESS=1` 强制开启。
- 隐身模式下窗口被移到屏幕外且不激活，**不会出现在任何桌面**，因此你随时增删桌面都不受影响。
- 需要真的看窗口时，正常 `open /Applications/网盘管家.app` 即可。
- `NETMOUNT_SNAPSHOT_JS` 里可以顺手改界面状态再截图，比如滚到编辑器下半部分：
  `openEditor(state.drives[0]); setTimeout(()=>{document.querySelector("#editorOverlay .body").scrollTop=980},400)`

### 菜单栏与原生面板自检

`takeSnapshot` 只能拍到 WKWebView，菜单栏和 NSPopover 都是原生视图，拍不到。这两个开关专门解决这件事：

```bash
# 打印菜单结构：▣ 表示这一项有图标，▢ 表示漏了；同时把面板渲染成 PNG
NETMOUNT_DUMP_STATUSBAR=1 NETMOUNT_DUMP_POPOVER=1 \
NETMOUNT_SNAPSHOT_POPOVER=/tmp/popover.png \
  /Applications/网盘管家.app/Contents/MacOS/NetMount
```

- `NETMOUNT_DUMP_STATUSBAR=1`：逐行打印菜单项、勾选状态与图标有无，改菜单后先跑这个，能立刻看出哪项忘了配图标。
- `NETMOUNT_DUMP_POPOVER=1`：构建左键面板并打印实际尺寸（应等于 `170 + min(盘数×44+8, 300)`）。
- `NETMOUNT_SNAPSHOT_POPOVER=<png>`：把面板用 `cacheDisplay` 渲染成图片，布局改了可以直接看。

### 看门狗日志

掉线重挂的每一步决策都能打出来，排查「为什么没自动重连」时看这个：

```bash
# 打印每轮扫描、死活判断、重连次数与退避倒计时
NETMOUNT_LOG=1 open /Applications/网盘管家.app

# 隐身模式下也想让看门狗跑起来（默认隐身不启动监控）
NETMOUNT_HEADLESS=1 NETMOUNT_FORCE_WATCHDOG=1 NETMOUNT_LOG=1 \
  /Applications/网盘管家.app/Contents/MacOS/NetMount
```

日志形如：`[看门狗] 第 12 轮：扫到 2 个网络卷，盯着 2 块盘` → `活着 1 块；掉线 1 块；假死 0 块` → `「极空间HD」连接已断开` → `开始第 2 次重连，失败的话 60 秒后再试`。

### 关于「让应用待在固定桌面」

应用自身的弹窗（添加 / 编辑磁盘）都画在主窗口里，永远跟主窗口在同一个桌面，不会单独跑出去。

想让整个应用固定待在某个桌面：在 Dock 上右键图标 → **选项** → **分配给** → 选「此桌面」（或某个桌面）。这个设置跟着桌面走，之后新增桌面也不影响。
