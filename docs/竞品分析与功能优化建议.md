# 网盘管家（NetMount）竞品对比与功能优化建议

> 编写日期：2026-10-26 · 版本基线：1.3.0
> 目的：对标 macOS 上同类「网络磁盘 / NAS 挂载管理器」，找出网盘管家还能优化的功能点。

---

## 一、竞品全景

macOS 上「把远程/网络磁盘挂成本地卷」的工具有两类，网盘管家属于**第一类（局域网 / NAS 管理器）**：

| 类别 | 代表产品 | 定位 |
|------|----------|------|
| **局域网 / NAS 自动挂载**（与网盘管家直接竞争） | **AutoMounter**（Pixeleyes）、**Mountain**（appgineers） | 菜单栏常驻，管理 SMB/WebDAV/AFP/NFS，自动挂载/重连 |
| **云盘 / 远程服务器挂载** | CloudMounter、Mountain Duck、ExpanDrive、NetDrive、WebDrive | 把 Dropbox/Google Drive/S3/SFTP/FTP 等挂成本地盘，常带加密 |
| **文件管理器顺带挂载** | Transmit、Commander One、ForkLift | FTP/SFTP/云，挂载是附属能力 |

**直接竞品**是 AutoMounter 与 Mountain；CloudMounter / Mountain Duck 在 WebDAV/SFTP 协议上与网盘管家**部分重叠**，可作为功能参考。

> 关键结论：**网盘管家在「自动发现 + 自动重连 + 唤醒重挂 + 强制卸载」这块已经和 AutoMounter/Mountain 拉平甚至更稳**（Bonjour 兜底发现是独有优势）。真正的短板集中在四件事：**唤醒 NAS、按网络位置挂载、菜单栏弹窗体验、用户可见的设置导入导出**。

## 三、已经做得好、不要动的部分

- **Bonjour 自动发现 + 网段扫描兜底**：局域网 NAS 一键发现，竞品基本没有。
- **掉线自动重连 + 唤醒重挂 + 系统通知**：`autoRemount` 默认开、`MountWatchdog` 轮询、`didWakeNotification` 已覆盖，是核心卖点。
- **强制卸载**：`diskutil unmount force` / `umount -f` 处理假死挂载点，已很稳。
- **SMB 版本协商 + `ipHint` + 只读 + 每盘凭据**：细节到位。
- **轻量菜单栏设计 + 内置使用说明书**：体验基础好。

## 四、功能优化建议（按性价比排序）

### 🔴 Tier 1 — 与核心定位强相关、性价比最高（建议作为 1.4.0 主题「更聪明的自动挂载」）

1. **唤醒 NAS（Wake-on-LAN）**
   - 现状：NAS 常处于休眠/关机，挂载时只能干等或失败。AutoMounter 将其作为关键卖点，网盘管家完全没有。
   - 做法：每个盘记录 NAS 的 MAC（发现时顺手存），挂载前若不可达先发 UDP magic packet，等几秒再挂。
   - 价值：极高（精准命中 NAS 用户痛点）；工作量：中（广播 magic packet + 存 MAC/IP）。

2. **网络/位置感知自动挂载（SSID 白名单）**
   - 现状：只要启动就尝试自动挂载，笔记本带到公司/咖啡厅会一堆失败报错。
   - 做法：用 CoreWLAN 取当前 Wi-Fi SSID，每个盘可设「仅在这些网络自动挂载」，不在名单里就跳过。
   - 价值：高（消除误报、提升专业感）；工作量：低。

3. **菜单栏弹窗（Popover）升级**
   - 现状：只有右键菜单，看不到各盘实时状态，挂载/卸载要进主窗口。
   - 做法：点击图标弹出 `NSPopover`，内嵌现有 HTML，显示各盘绿/灰连接点、容量条、一键挂载/卸载、打开主窗口。
   - 价值：高（与 Mountain/AutoMounter 体验拉齐，第一眼就专业）；工作量：中（复用 `ui.html` + `NSPopover`）。

4. **发现即添加（一键导入共享）**
   - 现状：发现列表里已有 `shares` 字段，但添加盘仍要手填主机/共享。
   - 做法：发现结果直接列出可用共享，点一下就生成盘配置。
   - 价值：中（显著降低首次上手成本）；工作量：低。

### 🟡 Tier 2 — 体验增强

5. **全局快捷键**：一键「挂载全部 / 打开窗口」，工作量低。
6. **用户可见的设置导入/导出**：把已保存盘列表导出为 JSON 文件、可再导入（目前只有「导入当前已挂载」，没有文件级备份/迁移），利于换机。工作量低–中。
7. **「全部挂载 / 全部卸载」批量操作**：主窗口加两个按钮，循环调用现有 mount/unmount。工作量低。
8. **更细的通知与诊断**：在已有「掉线/重连」通知基础上，补充「NAS 离线」「认证失败→引导重填密码」「WOL 唤醒中」等场景文案。

### 🟢 Tier 3 — 进阶 / 差异化（按需，不建议全做）

9. **AFP 协议支持**：兼容旧 NAS / Time Capsule，`mount_afp` 即可，优先级低。
10. **用量趋势图**：在历史容量曲线（纯前端），锦上添花。
11. **远程盘（SFTP/FTP）挂载**：超出「局域网」定位，且需 macFUSE，建议不做或拆成独立产品。
12. **Finder 扩展徽标（类似 Mountain Duck）**：工作量大，优先级低。

---

## 五、建议的下一步

- **1.4.0（主题：更聪明的自动挂载）**：拿下 Tier 1 的 ① 唤醒 NAS + ② SSID 感知 + ③ 菜单栏弹窗。这三件组成一个完整故事——「到家 Wi-Fi 自动唤醒 NAS 并挂好盘，菜单栏一眼看状态」，正好踩在 AutoMounter 的差异化卖点上，且网盘管家有 Bonjour 发现的独有优势打底。
- **1.4.x / 1.5.0**：Tier 2 的导入导出、批量操作、全局快捷键。
- 定价参考：竞品多为一次性 $10–30 或订阅；网盘管家目前免费独立，可保持免费并用「局域网发现 + 唤醒 NAS」作为口碑点。
